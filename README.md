# 寻忆 Android Demo

面向家庭记忆的原生 Android 演示应用与轻量后台。Android 页面遵循项目的暖奶油色、清晰文字、大触控区域设计规范，重点展示录音原声、记忆整理、地点绑定与家庭共忆。

## 当前演示边界

地点服务使用服务器端高德 Web 服务接口：录音提到地名且有同次 GPS 样本时按 GPS 绑定；没有 GPS 时搜索当前地图候选，由用户核对地图标点、名称、地址和依据后确认。记忆详情显示服务器代理的高德静态地图。

家庭谈话页要求参与者先同意，只提交用户主动输入的文字；开放问题由后台规则生成。实时收音、说话人识别、语音识别和大模型能力均标注“等待官方 SDK 下发后进行补充”。

服务器 Key、SSH 私钥和访问令牌均不随仓库发布。App 使用固定 HTTPS 服务地址，比赛演示凭证在本地构建时从仓库外文件注入 APK；普通页面不显示服务设置。APK 中凭证可提取，仅适用于受控演示，赛后轮换。
