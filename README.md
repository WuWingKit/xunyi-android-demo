# 寻忆 Android Demo

面向家庭记忆的原生 Android 演示应用与轻量后台。公开发布的 APK 无需账号：示例故事、编辑记录和共忆文字留在设备上；记忆地图通过高德官方 URI 页面联网展示，不包含后台访问令牌或高德 Key。Android 页面遵循项目的暖奶油色、清晰文字、大触控区域设计规范。

## 当前演示边界

公开 APK 的记忆地图使用高德官方 URI API 展示三个示例区域；地图需要网络，不能把示例坐标当成历史地点。地点搜索页会打开高德搜索结果供人工核对，下方可确认的候选仍是本机演示数据，并不自动对应地图 POI。仓库中的 `backend/` 保留服务端 GPS 证据和 API 的研究原型；它不被公开 APK 调用，不能把其能力算作公开 APK 已实现功能。

家庭谈话页要求参与者先同意；手机麦克风录音保存在 App 私有目录，用户核对后输入的文字和规则生成的开放问题也只保存在本机。实时转写、说话人识别、记忆珠通信和大模型能力仍待接入。

服务器 Key、SSH 私钥和访问令牌均不随仓库发布。公开 APK 仅为高德地图页面请求网络权限，不注入任何服务器凭证。旧版私有 APK 已从 Release 移除；不要把旧包重新上传到公开仓库。
