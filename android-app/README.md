# 寻忆 Android Demo

原生 Android Java 应用，按暖奶油色、清晰文字、大触控区域设计。底部为“首页／记忆／共忆／我的”。开发顺序和问题清单见[详细检查与设计](../DESIGN_REVIEW_2026-09-27.md)。

## 演示路径

1. 首页直接看到家庭记忆，设备卡显示当前连接状态。
2. 记忆页搜索 3 条本机示例记忆。第一条由 2 段独立讲述组成，可分别播放；示例讲述使用本地演示配音。首页也可进入录音收件箱，逐段查看讲述与关联记忆。
3. 记忆页的“打开记忆地图”通过高德官方 URI 页面在真实底图上展示 A/B/C 示例区域；需要网络，且示例坐标不是历史地点证明。点“核对录音中的地点”可看高德地点搜索结果，再选择本机演示候选并确认绑定；本机候选不是高德实时 POI 返回值，两者不自动对应。
4. 记忆详情可修改本机故事、调用系统分享面板分享文字，或删除整理结果而保留原始讲述。
5. 共忆页以语音为主要入口。参与者同意后点“开始说话”，手机麦克风录制本轮讲述，同时显示时长和音量；结束后核对演示转写并生成开放追问。文字轮次只保存在本机，手机朗读规则追问；本轮声音可回听。实时语音识别及大模型能力仍待接入。

公开包不调用项目 HTTPS 后台；除用户打开高德地图/地点搜索时请求地图页面外，故事、地点确认、共忆文字与录音均留在 App 私有存储，卸载 App 会删除这些数据。设备通信、录音豆音频、实时语音识别和模型推理仍需后续开发。`backend/` 是单独的服务端研究原型，不能和公开包混同。

## 构建与运行

使用 Android Studio 打开本目录，JDK 21、Android SDK 36。若 Gradle 依赖尚未缓存，可用本地 SDK 工具：

```powershell
.\build-demo.ps1
$env:ANDROID_AVD_HOME = 'E:\Android\Avd'
E:\Android\Sdk\emulator\emulator.exe -avd Pixel_7_API_36 -port 5558
```

确认 `adb -s emulator-5558 emu avd name` 返回 `Pixel_7_API_36` 后安装 `build-manual/xunyi-demo.apk`。5555 端口的雷电模拟器不能作为安装目标。

调试构建不需要演示令牌。不要把签名文件或构建 APK 推入 Git；公开包内没有后台凭证。

## 0.0.1 alpha 发布包

应用图标采用“声纹年轮”造型，使用品牌绿与暖杏色；共忆与“我的”页使用同一套老人、录音矢量图标。发布版本号为 `0.0.1-alpha`（versionCode 1）。

```powershell
.\build-release.ps1
```

发布构建需要提供仓库外的签名配置，输出 `build-manual/xunyi-v0.0.1-alpha.apk` 和对应 SHA-256 文件。签名配置和私钥不得提交到仓库。以后升级版本必须保留同一发布私钥；普通调试包与发布包使用不同签名，不能直接覆盖安装。

公开发布包可直接安装并离线体验。曾经使用共享后台令牌的私有测试包已从 Release 移除，不能再次公开分发。
